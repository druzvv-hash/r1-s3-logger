# R1-S3 Logger

[English](README.md) | **Українська**

Відновлений Logger R1 на **ESP32-S3 + INA228**. Поточна прошивка **PANEL v0.18**: панель тестів через USB/Wi-Fi, показники, налаштування з явним збереженням в EEPROM, заглушка енкодера й запис через FIFO у PSRAM та блоки на microSD. Виміри працюють на 10/50/100 Гц, графік — до 60 FPS. Запис сесій на SD доступний через Start/Stop. [Як записати й завантажити файл](docs/uk/RECORDING.md).

У вкладці **Файли SD** можна переглядати папки й завантажувати файли з картки через
USB або Wi-Fi. [Коротка інструкція](docs/uk/SD_FILES.md).

**Керування:** запусти [device_ui/start.cmd](device_ui/start.cmd) з платою на UART.
Для телефона назва мережі та пароль є в діагностиці панелі; адреса у Wi-Fi логера —
192.168.4.1. [Як проводити тести](docs/uk/TEST_PANEL.md).

## Апаратна архітектура

- ESP32-S3-WROOM-2-N32R16V (MCN32R16V): 32 MB Octal Flash, 16 MB Octal PSRAM.
- I²C на GPIO8/9: INA228 (0x40), OLED SH1106 128×64 (0x3C), EEPROM 24C32 (0x50), RTC DS3231 (0x68).
- SD через SPI: CS=10, MOSI=11, SCK=12, MISO=13.
- INA228 ALERT=14; зовнішній шунт 60 мВ / 400 А (150 мкОм).
- OLED повернуто на 180°. UART/CP210x на поточному ПК — COM5.

Докладні підключення: [pinmap](hardware/pinmap.md). Ревізія плати та схема SD-модуля потребують документування.

Для локального керування вибрано Bourns PEC11R-4220F-S0024; ще не встановлений. [Енкодер і буфери](docs/uk/BUFFERING_AND_ENCODER.md).

## Підтверджені результати

| Вузол | Стан |
|---|---|
| Flash/PSRAM | Визначаються; стрес-тест не виконано |
| I²C | Чотири адреси, повторні сканування без помилок |
| SD | 10 MHz, запис/закриття/перемонтування/читання PASS; файли перевірено на ПК |
| OLED | SH1106 128×64, зображення і поворот підтверджено |
| EEPROM | Власник підтвердив EEP PASS: backup, тест запису, повне порівняння після відновлення |
| RTC | UTC встановлено з браузера; OSF=0, хід PASS; час зберігся після відключення основного живлення |
| INA228 | Свіжі вимірювання й звірка напруги власником підтверджені; незалежне калібрування струму й ALERT попереду |

Після перепаювання USB-UART контролерів автоматичні прошивання проходили успішно. Точну причину попередніх збоїв не встановлено. Native USB порт поки не підтверджено.

## VS Code / PlatformIO

Відкрити всю папку **C:\Projects\r1-s3-logger**, встановити PlatformIO IDE. Arduino platform зафіксована на espressif32 6.12.0 (Arduino 2.0.17); OLED — Adafruit SH110X 2.1.12.

```sh
pio run
```

Профіль за замовчуванням — `esp32-s3`: UART із автоматичним скиданням, COM5, 115200. Перед прошиванням закрити Termite/Serial Monitor.

```sh
pio run -e esp32-s3 -t upload
pio device monitor -e esp32-s3
```

`esp32-s3-uart-manual` — запасний режим BOOT + RESET, після Upload потрібен ручний RESET. `esp32-s3-usb` — ще не підтверджений native USB. Окремий `esp32-s3-service` містить тести із записом у SD/EEPROM.

## Поточна поведінка

Звичайний запуск перевіряє читання SD й двічі читає EEPROM; тестові файли та шаблони більше не записує. На дисплеї `SD READ / SAVED` — налаштування збережені; UNSAVED — є незбережені значення. Показники напруги й струму, поворот 180°, перевірки RTC/I2C збережено. Час змінює тільки явна [команда синхронізації](docs/rtc-sync.md).

[P0/P1: що зроблено і що далі](docs/uk/P0_P1_RESULTS.md). Нові формати налаштувань і записів уже мають еталонні файли та перевірки на ПК; реєстратор уже створює самодостатні файли на SD. P2 готовий: запустити `viewer/start.cmd`. [Вювер і результати](docs/uk/P2_VIEWER.md). [P3: налаштування й EEPROM](docs/uk/P3_SETTINGS.md) реалізовані. Частота вимірів уже перемикається в панелі. P5 уже записує файли на SD; тепер є реальні записи для перевірки та розвитку вювера. Поточний інтерфейс ще не замінює повноцінний R5.

[Тест 3 А / 3 В](docs/uk/LOAD_TEST_2026-09-08.md): 10/50/100 Гц без пропусків і помилок I2C; 40 перевірених завантажень із SD під час вимірів на 100 Гц. У v0.17 виправлено затримку оновлення стану панелі.
