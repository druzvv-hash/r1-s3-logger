# Прошивка

PlatformIO + Arduino для ESP32-S3. Конфігурація лежить у корені репозиторію; команди `pio run`, `pio run --target upload` і `pio device monitor` виконуються звідти.

- `src/main.cpp` — стартовий каркас без драйверів і логіки старого R1.
- `include/pins.h` — GPIO, узгоджені з `hardware/pinmap.md`.

Профіль плати попередній: уточнити Flash, PSRAM і спосіб підключення Serial перед прошиванням. Версію платформи поки не зафіксовано; після першої перевіреної збірки записати її та закріпити в `platformio.ini`.

Перший майбутній тест — сканування I²C на GPIO8/9 при 100 kHz. Далі додавати тести окремими кроками за `docs/bring-up.md`. Залежності драйверів обирати після уточнення модулів. Калібрування, CSV, буферизація, OLED UI та Web UI залишаються наступним етапом.
