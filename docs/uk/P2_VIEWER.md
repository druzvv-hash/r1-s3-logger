# P2 — офлайн-вювер готовий

Запуск: відкрити `viewer/start.cmd` у папці репозиторію. Відкриється браузер; вибрати або перетягнути CSV. Інтернет і підключений прилад не потрібні. На цьому ПК Python уже є. Для іншого ПК потрібен Python 3.10 або новіший, без додаткових пакетів.

Є два графіки, вибір часового діапазону й окремого сегмента після скидання часу. Короткі піки зберігаються на загальному огляді. Середнє, мінімум, максимум, заряд та енергія рахуються за всіма придатними точками ділянки. Лічильник енергії з файлу показано окремо від перерахованої енергії. Пропуски й непридатні виміри не замінюються нулями й не з’єднуються.

Підтримано звичайні R1 CSV і новий R1S3 CSV v1. Для коротких заголовків і файлів без заголовка треба підтвердити значення колонок у налаштуваннях імпорту. `Pss_Wh` лишається окремим каналом із непідтвердженим змістом. Бінарні LYLI/R3 — етап P8.

Перевірено 84 файли з архіву: 70 відкрилися автоматично, разом 2 870 946 рядків; 14 потребують підтвердження формату. Оригінали не змінювалися. Пройшли 29 автоматичних тестів та перевірка інтерфейсу в Chrome.

Новий синтетичний CSV на 350 тисяч рядків (20,9 MB) прочитано з усіма контрольними сумами. Тимчасова база займає більше місця за CSV; великі файли можуть відкриватися довго. Повний звіт: [P2 англійською](../P2_VIEWER.md).

Прошивка й EEPROM цього разу не змінювалися. Наступний етап — P3: застосування, перевірка та надійне збереження налаштувань у EEPROM.
