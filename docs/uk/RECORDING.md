# Запис вимірювань на microSD

1. Відкрий панель логера. Перед записом вибери частоту та перевір показники.
2. Натисни **«Почати запис»**. Дочекайся стану **«ЗАПИС»**.
3. Проводь тест. Браузер можна закрити — логер продовжить запис самостійно.
4. Натисни **«Зупинити й зберегти»** та дочекайся **«Файл збережено»**.
5. Натисни **«Відкрити записи»**, потім **«Завантажити»** біля потрібного CSV.

Панель показує тривалість, кількість відліків, розмір, енергію, заряд і стан буфера.
На OLED під час запису видно `REC:RUNNING`, при завершенні — `REC:STOPPING`.
Частоту, час та налаштування змінюй між записами. Читання файлів також доступне
після Stop. Кнопка **«Пауза графіка»** зупиняє тільки графік.

Файли лежать у `/records`. У кожному є налаштування, коефіцієнти, сирі значення
INA228, час і контрольні суми; EEPROM для відкриття файлу у вювері не потрібна.
З v0.19 назва містить дату й час початку, наприклад
`r1s3_2026-09-08_10-55-37Z_4ee24d5b_9ebc8459_0000.csv`.
`Z` означає UTC, останні чотири цифри — номер частини. У списку під назвою
видно місцевий час браузера: для Праги цього дня це **08.09.2026 12:55:37**.
Час показується і для старих файлів із числом Unix у назві. Якщо RTC не заданий
і запис без часу явно дозволений, у назві буде `time-unknown`.
При досягненні заданого розміру логер створить наступну частину тієї ж сесії.
Буфер — у PSRAM, запис на картку — блоками по 8 KiB з періодичною синхронізацією.

Під час запису файл має розширення `.part`. Після успішного завершення — `.csv`.
Якщо сталася помилка, `.part` залишається для перевірки; логер не видаляє його й
не позначає успішним. Вювер уміє показувати перевірену частину незавершеного файлу.
Не виймай картку, доки триває запис або збереження.

При переході на 10 Гц швидке перемикання частоти також збільшує допустиму паузу
між відліками до 200 мс, якщо старе значення менше. Це потрібно для коректного
рахування енергії. Збереження зміненого профілю в EEPROM залишається окремою дією.
