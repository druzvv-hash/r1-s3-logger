# Панель тестів R1-S3

На ПК запускай device_ui/start.cmd. Плата підключається через **UART / COM5**.
Termite і Serial Monitor мають бути закриті. Панель тестів працює окремо від в’ювера файлів.

1. **Огляд:** напруга, струм, потужність, температура, графік і стан вузлів.
2. **Налаштування:** змінюй параметри, перевір різницю, натисни **Застосувати**.
   Лише кнопка **Зберегти в EEPROM** збереже їх для наступного запуску.
3. **Діагностика:** сканування I²C, читання SD, два читання EEPROM і вимір INA228.
   Ці тести не створюють файлів і не пишуть тестових шаблонів в EEPROM.
4. **Час із цього пристрою → RTC:** записує UTC з годинника ПК/телефона.
5. Для прошивання: **Діагностика → Звільнити USB для прошивання** або device_ui/stop.cmd.
   Після прошивання знову запусти start.cmd.

Для телефона в діагностиці показані назва мережі R1-S3 та пароль.
Підключись до цієї Wi-Fi мережі, погодься залишитися без інтернету й відкрий
http://192.168.4.1/. Для такого підключення ПК не потрібен.

Зараз це діагностичні виміри приблизно **1 раз на секунду**. Налаштування частоти
10/50/100 Hz вже є у профілі, але робочий збір із цією частотою — наступний етап.
Запис сесій на SD ще не підключений. FIFO в PSRAM і блок SD підготовлені; енкодер
залишається заглушкою без призначених GPIO.

Калібрування не змінюється автоматично. Значення 150 µΩ відповідає шунту 400 A / 60 mV.
Після зміни розміру FIFO потрібно зберегти налаштування й перезапустити плату.
