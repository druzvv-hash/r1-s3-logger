# Файли з картки через панель

1. Відкрий панель логера та вкладку **Файли SD**.
2. Натисни **Оновити список**.
3. Біля потрібного файлу натисни **Завантажити**.

Файл збережеться через стандартні завантаження браузера. Там видно прогрес,
можна скасувати завантаження і перевірити, чи воно завершилося. Файл на microSD
залишається. Для папок є кнопки **Відкрити** та **На рівень вище**.

Через USB комп’ютер залишається у своїй мережі. Великі файли краще передавати
через Wi-Fi логера. Одночасно читається один файл або список папки; якщо бачиш
повідомлення про зайняту картку, дочекайся завершення передачі й онови список.
Після тривалої паузи також може знадобитися оновлення списку.

Я можу завантажувати файли через цю саму панель для перевірки їхнього вмісту.
[Запис нових вимірювальних сесій](RECORDING.md) доступний у v0.18. Завантажуй
файли після завершення запису кнопкою Stop.
