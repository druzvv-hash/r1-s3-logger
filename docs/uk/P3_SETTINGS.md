# P3 — налаштування логера

Прошивка CONFIG v0.12 уже має 28 параметрів із зафіксованої схеми: шунт, полярність, нулі/коефіцієнти, режими INA228, налаштування дисплея та майбутнього запису.

- Імпорт JSON створює чернетку; APPLY перевіряє й застосовує її; SAVE окремо зберігає.
- EEPROM містить дві копії. Завантаження нічого не записує, змінені значення позначаються UNSAVED.
- Перевірили на платі A → B → A та відновлення після RESET. Зараз збережені початкові налаштування, покоління 3: шунт 150 мкОм, полярність +1, коефіцієнти 1, нулі 0, яскравість 127. Калібрування не оголошене виконаним.
- Резервні образи EEPROM залишені приватно в Documents/R1-S3 Backups.
- Пройшли 33 тести на ПК. Обрив запису й відкат регістрів перевірені імітацією; фізично живлення посеред запису не відключали.

Керування зараз через tools/settings.py: export → редагування JSON → import → apply → save. Докладні команди й обмеження: [P3_SETTINGS.md](../P3_SETTINGS.md).

Наступний етап — P4: постійне вимірювання, фактична частота й черга. Потім P5: самодостатні файли на SD. Вювер допрацьовуватимемо на цих файлах. Поле requested_rate_hz уже зберігається, але діагностична прошивка поки вимірює приблизно раз на секунду.
