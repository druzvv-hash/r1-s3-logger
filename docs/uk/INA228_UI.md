# INA228 та графік у панелі логера

У **Огляді**, під графіком, є блок **INA228 · шум і швидкість**.

1. Вибери усереднення: ×1 означає без усереднення, далі ×4, ×16…×1024.
2. За потреби зміни час конверсії шунта, напруги та температури.
   Довші конверсії й більше усереднення зазвичай зменшують шум, але уповільнюють реакцію.
3. Панель показує час повного циклу та розрахункову допустиму частоту.
   Якщо обраний режим не встигає, можна явно натиснути **Узгодити частоту**
   або зменшити усереднення/час конверсії. Нічого не перемикається самостійно.
4. Натисни **Застосувати INA228**. Для збереження після вимкнення живлення
   окремо натисни **Зберегти в EEPROM**.

Наприклад, за конверсій 1052 мкс на кожен із трьох каналів:

| Усереднення | Час АЦП | Розрахункова межа з резервом |
| --- | ---: | ---: |
| ×1 | 3,156 мс | 176 Гц |
| ×4 | 12,624 мс | 60 Гц |
| ×16 | 50,496 мс | 18 Гц |

Це розрахунок сумісності налаштувань, а не результат тривалого тесту на кожній частоті.
На 50 Гц можна почати з ×4 і порівняти шум із ×1. Якщо потрібне ×16 без зниження
частоти, доведеться вибрати коротші конверсії та перевірити результат.

Чутливий діапазон ±40,96 мВ має менший крок, але зі шунтом 150 мкОм
його межа — приблизно ±273,1 А. Для всього діапазону шунта 400 А / 60 мВ
потрібен широкий діапазон. Розрахована межа АЦП не є допустимою потужністю шунта.

Верхній вибір частоти за замовчуванням зберігає встановлені параметри INA228.
**Авто ADC · скинути усереднення** потрібно вибрати явно, якщо хочеш використати
попередні автоматичні швидкі режими. Спільна чернетка також містить зміни з
вкладки «Налаштування»; перевір список перед застосуванням. Під час запису
застосування та збереження заблоковані.

## Навігація по графіку

- **Ділянка 10 / 30 / 60 с** задає ширину вікна.
- Коліщатко масштабує час біля курсора; **＋ / −** — біля середини вікна.
- Перетягуй графік горизонтально або користуйся **← / →**. На телефоні
  доступні ті самі кнопки.
- **Наживо** або подвійний клік повертає до нових вимірів.
- Перегляд старішої ділянки не припиняє збирання нових точок.
  **Пауза графіка** заморожує графік, виміри й запис на SD продовжуються.

У вкладці накопичується до 3 хвилин отриманих даних. До відкриття сторінки
ця історія не зберігається; для довших записів використовуй файли SD та вювер.
Пропуски потоку залишаються розривами. 60 FPS — частота малювання, окрема від
частоти вимірів. Масштаб напруги та струму підбирається незалежно для видимої ділянки.
