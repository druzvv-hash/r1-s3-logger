# Керування через Wi-Fi

## Спільна мережа (від 0.33-lan-dev)

R1 автоматично підключається до збереженої мережі 2,4 ГГц. Телефон/ПК залишай
у цій самій мережі й відкривай **http://r1-s3-7455.local/** для поточного приладу.
Якщо `.local` не відкривається, використай IP із вкладки **Wi-Fi → Спільна мережа**.
Адресу видає роутер; після зміни мережі вона може змінитися.

На цьому приладі підготовлено профілі TP-Link_CC06, dlink_DWR-932_4280 та iPhone.
Паролі взято зі збережених профілів Windows і записуються в NVS логера.
Для iPhone увімкни сумісність 2,4 ГГц. Мережу тільки 5 ГГц ESP32-S3 не підтримує.
У UI можна зберегти нову основну мережу; інші два профілі лишаються резервними.
Невдале підключення перемикає профіль через 20 секунд, не зупиняючи вимірювання.
Для доступу між пристроями роутер не повинен ізолювати Wi-Fi клієнтів.

## Резервна точка доступу

Якщо роутера немає поруч, панель доступна через мережу самого логера.
ПК-сервер для обох способів не потрібний.

1. У панелі ПК відкрий вкладку **Wi-Fi**. Там зазначена назва мережі приладу;
   пароль відкривається кнопкою **Показати пароль Wi-Fi**.
2. Підключи телефон до цієї мережі. Якщо Android попереджає про відсутність
   інтернету, вибери **Залишатися підключеним**.
3. Відкрий **http://192.168.4.1/**. Угорі панелі має бути позначка **Wi-Fi**,
   а у вкладці Wi-Fi — **Wi-Fi напряму**.
4. У **Огляд** починай і зупиняй запис. Після зупинки відкрий **Файли SD**
   і завантаж потрібний CSV.

Закриття браузера не зупиняє запис. При поверненні спочатку перевір його стан;
логер увесь час має залишатися під живленням. Кількість пристроїв у Wi-Fi означає
кількість підключених до мережі клієнтів, навіть якщо їхній браузер закритий.

08.09.2026 перевірено через Wi-Fi-адаптер ПК з вимкненим USB-сервером: Start/Stop,
10 секунд із закритим браузером, 541 відлік без пропусків та завантаження CSV.
Файл пройшов контроль цілісності й читання у вювері. Завантаження попереднього
файлу на 615 956 байтів також пройшло; панель відповідала під час передачі.

Це перевірка на ПК з вузьким вікном Chrome. Роботу Android із мережею без
інтернету та збереження завантаженого файлу на телефоні ще потрібно підтвердити.
ПК після тесту повернуто до його попередньої мережі, логер залишено READY / 50 Гц.

Технічні результати: [P6 Wi-Fi](../P6_WIFI.md).

## Виправлення 10.09.2026

На 0.24 відтворилося зависання завантаження панелі при сильному сигналі;
через UART вимірювання продовжувалися. У 0.25 звільнено 28 КБ внутрішньої
пам'яті та змінено передавання сторінки на блоки по 1 КБ.

Два повторні підключення ПК без перезапуску ESP пройшли: панель, дві вкладки,
показники, список SD та малий тестовий файл. BLE лишався увімкненим.
Одне перерване мережеве звернення відновилося автоматично; перевірку саме
на телефоні ще потрібно повторити. [Повний звіт](../WIFI_STABILITY_2026-09-10.md).

Адреса `127.0.0.1:8767` — USB-панель на ПК. Для прямого Wi-Fi використовуй
`http://192.168.4.1/`, підключившись до мережі R1. На Android підтвердь
«Залишатися підключеним», якщо з'явиться попередження про відсутність інтернету.
