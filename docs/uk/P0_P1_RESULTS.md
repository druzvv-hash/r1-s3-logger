# P0 і P1 — результати, 2026-09-07

P0 завершено на платі, P1 — як специфікації та перевірки на ПК. Це підготовка міграції, ще не новий реєстратор.

- Збережено робочу v0.10 тегом `hwtest-v0.10` і окремою локальною копією прошивки.
- На платі BASE v0.11: показники INA228 та екран залишилися; звичайний запуск лише перевіряє читання SD й EEPROM. Написи `SD READ / EEP READ` очікувані.
- EEPROM зчитано двома окремими запитами, копії збіглися. Приватний образ і контрольна сума збережені в `Documents/R1-S3 Backups`, у Git не публікуються.
- Автоматичне прошивання UART успішне; після RESET чотири I2C-адреси, INA228 ADC OK, хід RTC PASS.
- Тести, що пишуть у SD/EEPROM, відокремлено в `esp32-s3-service`. Типовий профіль — `esp32-s3`.
- Зафіксовано 28 налаштувань: шунт, полярність, коефіцієнти, режими вимірювання, запису, дисплея та дані калібрування. Формат двох копій EEPROM має версію, покоління, CRC і ознаку завершення.
- Новий CSV міститиме сирі відліки, готові значення, застосовані коефіцієнти, час, пропуски та перевірки цілісності. Його можна буде розібрати без самого приладу.
- Підготовлено синтетичні файли й еталонний читач. Старі записи не змінюються. Для `Pss_Wh` точне значення ще не підтверджено вихідником; вювер мусить показувати цю невизначеність.

Документи англійською: [налаштування](../CONFIG_SCHEMA.md), [формат запису](../FILE_FORMAT.md), [сумісність вювера](../VIEWER_COMPATIBILITY.md), [P0](../P0_BASELINE.md).

Наступний етап P2: офлайн-вювер із читанням підтвердженого R1 CSV і нового R1S3 CSV. Реальний запис налаштувань у EEPROM — P3, виробниче вимірювання — P4, реєстратор SD — P5. ALERT, точність струму та тривалі тести залишаються відкритими.
