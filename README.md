# R1-S3 Logger

Відновлений Logger R1 на **ESP32-S3 + INA228**. Проєкт починається з перевірки апаратури; старий код R1 ще не перенесено.

## Апаратна архітектура

- **ESP32-S3** — керування периферією та майбутнє логування.
- **INA228** — вимірювання напруги та струму через зовнішній шунт; на тестовому стенді модуль винесено назовні. ALERT підключений окремо.
- **Спільна I²C-шина** — INA228, OLED, EEPROM 24C32 та RTC.
- **microSD через SPI** — майбутнє збереження вимірювань.
- **EEPROM 24C32** — заплановане зберігання калібрування; **RTC** — часові мітки; **OLED** — стан і вимірювання.

GPIO зафіксовані у [hardware/pinmap.md](hardware/pinmap.md). Моделі OLED/RTC, ревізія ESP32-S3, обсяг Flash/PSRAM, номінал шунта та адресні перемички ще потребують уточнення.

## Початок роботи

Встановити PlatformIO Core або розширення PlatformIO IDE та відкрити корінь цього репозиторію.

```sh
pio run
pio run --target upload
pio device monitor
```

Перед прошиванням звірити реальну плату з `platformio.ini`. Початковий профіль `esp32-s3-devkitc-1` у PlatformIO відповідає **N8 (8 MB Flash, без PSRAM)** — це тимчасове припущення, а не підтверджена комплектація стенда. Див. [офіційну документацію профілю](https://docs.platformio.org/en/latest/boards/espressif32/esp32-s3-devkitc-1.html).

Поточний каркас лише друкує повідомлення в Serial на 115200 бод. Периферію він ще не перевіряє. За замовчуванням використовується Serial через UART/USB–UART; параметри native USB слід обрати після уточнення плати та підключення.

Наступний крок — [hardware bring-up](docs/bring-up.md), починаючи з I²C scanner після повторної перевірки живлення. Перенесення функцій R1 почнеться після успішної перевірки всіх вузлів.
